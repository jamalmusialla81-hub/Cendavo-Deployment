# Cendavo site audit — 2026-10-13 (design/daylight @ b657766)

Three independent audits of the running build (code/backend, visual/interaction at 9 viewports, performance/accessibility with throttling). Lab numbers from a local server, not field data. No Lighthouse/axe available offline; checks were Playwright + CDP + manual.

## Working well (preserve)
- Static build (`scripts/build_site.py`), strict CSP (no inline script/style), self-hosted fonts, AVIF images, no tracking scripts.
- Enquiry backend: every real success (200/201) happens only after the row is durably in D1; idempotency key, throttle, origin check, size limits, field validation mirrored client/server; client keeps input on every failure, blocks double submit, announces status via `role="status"`, focuses the first invalid field.
- Showreel controller: chapters seek correctly, Pause truly pauses, state survives tab hide/show and scroll-away; vertical cut on phones.
- Before/after: range input works with mouse, touch, keyboard; labels/aria-pressed correct; no distortion.
- Mobile menu: aria-expanded, Escape, focus return. Every internal link resolves. No horizontal scroll, no console errors.
- Reduced motion: all content rendered immediately on every page, no WebGL/Lenis/autoplay.
- Accessibility basics: one h1 per page, ordered headings, landmarks, skip link first, all fields labelled, alt text, focus rings, glass text contrast ≥ 5.75:1.
- No fabricated testimonials, stats, awards or addresses; concept projects labelled throughout.

## Performance (local, Fast-4G throttled)
- LCP 2.3–3.3 s on `/`, `/services/`, `/pricing/`, `/work/` because the hero subheading is held at opacity 0 by the entrance (`.ph-wait`); the headline itself paints at ~0.8–1.1 s. `/about/`, `/contact/`, `/demo/` ≈ 0.8–0.96 s.
- `/work/` load event 6.3 s: a 593 KB hero video downloads before load; CLS 0.045 from hero copy/index moving at 1.8–4.2 s. All other pages CLS ≤ 0.016.
- Desktop pulls 0.8–1.4 MB after load (three.js 676 KB + SVGLoader 68 KB + BufferGeometryUtils 31 KB + scene modules), causing a 72–574 ms long task; inner pages load SVGLoader/glass-scene they barely use; a throwaway WebGL context is created just to feature-test.
- GSAP + ScrollTrigger tickers keep running (~124 rAF/s) after Pause motion and under reduced motion.
- Home WebGL hero ≈ 43 fps on an M2 (inner pages ≈ 60).
- INP proxy fine (≤ 100 ms Event Timing).
