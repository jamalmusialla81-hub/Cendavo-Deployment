# Cendavo development instructions

Cendavo is a website design, redesign and maintenance business for local service businesses in Sydney (owner decision 2026-10-11; see docs/FORGE_RECOVERY_AUDIT.md). Current increment: the business website, a browser-local request-queue demo kept as a labelled demonstration project (synthetic data), and an enquiry form backed by a Cloudflare Pages Function and D1 (docs/CENDAVO_TASK_1_RECOVERY.md). No payment, hosted customer accounts or outbound messaging exist.

Forge no longer invokes Codex; independent Claude reviewer sessions audit Builder code. If Codex is used manually, it audits Claude Builder's code and verifies test results. For any proposed feature, check security, user value, compatibility with Cloudflare Pages and whether the site accurately describes current capabilities. Do not present any price as validated. Never commit secrets or deploy production without explicit user approval. Keep all overnight automation local, bounded, auditable and stoppable. Use `python3 scripts/build_site.py` and `python3 -m unittest discover -s tests` for checks.
